# Boss feedback on Mia — plan (2026-10-09)

25 notes from testing the kiosk. Each is assigned to a wave and a chat.
Chats in the same wave run in parallel, each in its own git worktree branched
from the latest `simli-livekit-trinity`. The main chat reviews, merges and
deploys between waves.

Ownership rule (to keep parallel chats from colliding):
- **Chat P (persona)** owns `agent-worker/mia_prompt.txt` except the LANGUAGE
  section and the new PAUSING section, plus `team.json`.
- **Chat C (conversation control)** owns `agent-worker/worker.py` and the
  prompt's LANGUAGE + PAUSING sections.
- **Chat S (screen)** owns `src/` (kiosk panel, AI button, on-screen UI).
- **Chat A (audio)** investigates; code changes only if small and agreed.
